1. Словник базових англійських термінів

Filesystem - файлова система (ієрархічна структура для зберігання та організації файлів).   

Directory (Folder) - каталог або папка (тип файлу, який використовується для зберігання інших файлів та каталогів).   

Root directory - кореневий каталог (найвищий рівень ієрархії файлової системи, позначається як /).   

Home directory - домашній каталог (унікальний каталог, що призначається для кожного користувача під час його створення).   

Command Line Interface (CLI) - інтерфейс командного рядка (текстовий інтерфейс для взаємодії з операційною системою).   

Globbing (Wildcards) - підстановка (використання спеціальних символів на зразок * або ? для пошуку та маніпуляції шаблонами імен файлів).  

Recursive - рекурсивний (дія, яка застосовується не лише до об'єкта, а й до всіх його вкладених підкаталогів та файлів).   

Clobber / Overwrite - перезапис (знищення наявного вмісту файлу новим під час копіювання чи створення).   

2. Відповіді на завдання для попередньої підготовки
2.1. Порівняйте файлові структури Windows-подібної та Linux-подібної системи.

У Windows: Верхнім рівнем ієрархії є об'єкт «Мій комп'ютер» (My Computer), під яким розташовані фізичні чи логічні диски, позначені літерами (наприклад, C:, D:, E:). Кожний пристрій або розділ має власне дерево каталогу.  

У Linux: Ієрархія є єдиним цілим і починається з єдиного кореневого каталогу, що позначається слешем (/). У Linux немає понять дискових літералів (C:, D:); будь-які пристрої (жорсткі диски, флешки, мережеві сховища) «монтуються» (підключаються) як підкаталоги в єдину загальну деревоподібну структуру файлової системи.   

2.2. Розкрийте поняття FHS. Як даний стандарт використовується в контексті файлових систем?

FHS (Filesystem Hierarchy Standard) - це стандарт ієрархії файлової системи, який визначає назви каталогів та призначення їхнього вмісту в операційних системах сімейства Linux та Unix. Завдяки дотриманню FHS користувачі та розповсюджувачі дистрибутивів точно знають, де шукати системні конфігурації (/etc), двійкові файли програм (/bin, /sbin), тимчасові файли (/tmp) чи домашні каталоги користувачів (/home), незалежно від конкретного дистрибутива Linux.   

2.3. Перерахуйте основні команди для роботи з файлами та каталогами в Linux: створення, переміщення, копіювання, видалення.

Створення:
mkdir [каталог] -створення нового каталогу.   
touch [файл] - створення порожнього файлу.   

Копіювання:
cp [джерело] [призначення] - копіювання файлів; для копіювання каталогів використовується ключ -r (cp -r).   
Переміщення / Перейменування:
mv [джерело] [призначення] - переміщує файл/каталог у нове місце або перейменовує його, якщо вказати нову назву в межах того самого шляху.   

Видалення:
rm [файл] - видалення файлу (рекомендується з ключем -i для підтвердження).  
rm -r [каталог] - рекурсивне видалення каталогу з усім вмістом.   
rmdir [каталог] - видалення виключно порожнього каталогу.

4. Дії команд навігації по системі каталогів
cd / - перехід до абсолютного кореневого каталогу файлової системи (/).   
cd /home - перехід до каталогу /home, де зберігаються домашні папки користувачів системи.   
cd ~ - перехід до домашнього каталогу поточного користувача.   
cd (без аргумента) - аналогічно до cd ~, здійснює швидкий перехід до домашнього каталогу поточного користувача.   
cd .. — підняття на один рівень вище у батьківський каталог відносно поточної позиції.   
cd ../.. — підняття на два рівні вище в ієрархії каталогів.   
cd - — повернення до попереднього каталогу, у якому користувач перебував перед цим.

5. Відповіді на контрольні запитання
Як можна переглянути шлях до домашньої директорії користувача за допомогою команди echo?
Існує два основних способи за допомогою змінних середовища:   
echo $HOME
echo ~ (або echo $TILDE залежно від оболонки, проте стандартним є вивід через змінну $HOME або розгортання тильди echo ~).
Чи можна переглянути вміст кореневого каталогу, перебуваючи у домашньому каталозі користувача без переходу у кореневий каталог?
Так, для цього достатньо передати шлях до кореневого каталогу як аргумент команді виведення вмісту: ls /.   
Яким чином в терміналі можна додати інформацію в порожній файл?
За допомогою перенаправлення виводу команди echo: echo "Текст" > ім'я_файлу.   
За допомогою текстових редакторів (наприклад, nano ім'я_файлу або vim ім'я_файлу).
За допомогою потокового введення через cat: cat > ім'я_файлу (після введення тексту натискається комбінація Ctrl + D).
Як скопіювати та видалити існуючий каталог? Чи буде відмінність в командах, якщо каталог буде не порожній при цьому?
Копіювання: Звичайна команда cp не копіює каталоги за замовчуванням. Щоб скопіювати каталог (незалежно від того, порожній він чи ні), обов'язково використовується рекурсивний ключ -r: cp -r [джерело] [призначення].   
Видалення: Для порожнього каталогу можна використати rmdir [каталог] або rm -r [каталог]. Якщо каталог не порожній, команда rmdir видасть помилку; для його видалення разом із усім вмістом обов'язково застосовується рекурсивний ключ з rm: rm -r [каталог].   
У якому з наведених нижче прикладів відбувається переміщення файлу? його перейменування? одночасно обидві дії?
mv /work/tech/comp.png /Desktop - Переміщення файлу (файл comp.png переміщується у каталог /Desktop, зберігаючи свою початкову назву).   
mv /work/tech/comp.png /work/tech/my_car.png - Перейменування файлу (файл залишається в тій самій директорії /work/tech/, але змінює ім'я з comp.png на my_car.png).   
mv /work/tech/comp.png /Desktop/computer.png - Одночасно обидві дії (файл переміщується в новий каталог /Desktop і водночас отримує нову назву computer.png).
